Antes de instalar

Na estação, o Python precisa estar instalado para todos os usuários. Se não estiver, rode num terminal de administrador:
winget install -e --id Python.Python.3.13 --scope machine
Baixe o projeto pelo git pull ou pelo zip e copie a pasta agente/ para a estação.

Instalação

Clique com o botão direito no instalar.bat → Executar como administrador.
As 6 etapas devem terminar com “Instalacao concluida!”.
Reinicie o PC. Ele deve entrar sozinho como cliente e, uns 5 segundos depois, o agente abre em tela cheia.

Se o agente não abrir, entre como admin e me mande o resultado destes comandos:

schtasks /query /tn MatheCafe-Agente /v /fo list

O “Último resultado” indica se a tarefa rodou. 0x41303 quer dizer que nunca rodou; um código de erro quer dizer que o Python falhou.

C:\MatheCafe\venv\Scripts\python.exe C:\MatheCafe\agente.py

Esse roda o agente com o console aberto, para aparecer o erro.

Também vale conferir

Painel: a estação aparece online no painel.
Bloqueio: o bloqueio fecha os programas que não estão na lista de permitidos.
Auto-update: depois de uma atualização, o agente reabre normalmente. Isso confirma que o cliente consegue gravar em C:\MatheCafe.


1. Instalação (como administrador)
Baixe a pasta agente/ atualizada (git pull ou zip novo).
Clique com o botão direito no instalar.bat → Executar como administrador.
Deve aparecer: “Python encontrado” e “será copiado para C:\MatheCafe\python”.
Deve terminar: as etapas [1/6] a [6/6] sem nenhum “ERRO” e com “Instalacao concluida!”.
Confira: a pasta C:\MatheCafe existe e tem agente.py, agente.cfg, python\ e venv\.
2. Início automático (o objetivo principal)
Reinicie o PC.
Deve acontecer: o Windows entra sozinho como cliente, sem pedir senha.
Deve acontecer: uns 5 segundos depois, o agente abre em tela cheia.
No painel: a estação aparece online no Mapa.
3. Uso normal
Libere um cliente no painel e faça login com ele na estação.
Deve acontecer: a sessão começa e o tempo começa a contar.
Abra um app permitido: ele abre.
Abra algo que não está na lista (o Bloco de Notas, por exemplo): ele é fechado sozinho.
Encerre a sessão pelo painel: a estação volta para a tela de login.
4. Recuperação
Agente fechado à força: abra o Gerenciador de Tarefas, encerre o pythonw.exe e espere cerca de 1 minuto. O agente deve reabrir sozinho.
Queda da rede: desligue o servidor e ligue de novo. O agente deve reconectar e a estação volta a ficar online.
5. Auto-update (pode ficar para depois)
Esse teste só faz sentido quando houver uma versão nova do agente publicada no servidor.
Deve acontecer: o agente baixa a versão nova e reabre sozinho. Isso confirma que o cliente consegue gravar em C:\MatheCafe.
Se algo falhar

Entre como administrador (para sair do autologin, segure Shift ao reiniciar ou use o modo manutenção) e me mande o resultado destes dois comandos:

schtasks /query /tn MatheCafe-Agente /v /fo list
C:\MatheCafe\venv\Scripts\python.exe C:\MatheCafe\agente.py

O primeiro mostra se a tarefa rodou e qual erro deu. O segundo abre o agente com o console aberto, para aparecer o erro.

Os passos 1 e 2 são os que validam a correção de hoje. Os outros confirmam que o agente funciona rodando como cliente, sem admin, o que também é novidade.
